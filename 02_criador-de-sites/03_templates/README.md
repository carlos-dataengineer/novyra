# Templates futuristas

Os três templates são bases autorais do NOVYRA. Cada um é um HTML independente com CSS incorporado e pode ser aberto diretamente no navegador.

| Template | Perfil | Repertório |
|---|---|---|
| `lusion-3d-immersive` | Portfólio/landing com objeto protagonista e narrativa de experiência. | Lusion: storytelling, motion e 3D. |
| `takamo-cinematic-sci-fi` | Universo sci-fi, atmosfera espacial e conteúdo editorial. | Padrões cinematográficos da galeria DesignRush. |
| `databahn-tech-product` | Produto B2B de IA/tecnologia com dados e módulos claros. | Repertório DataBahn e DesignRush. |

Os elementos 3D são representações CSS, não cenas WebGL reais. Para produção, planeje assets, fallback, acessibilidade e orçamento de performance. Não são usados logos, imagens ou código dos sites de referência.
