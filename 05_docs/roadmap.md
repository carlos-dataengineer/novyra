# Roadmap da NOVYRA

Este roadmap registra uma direção de evolução. Os itens futuros são propostas e não devem ser confundidos com funcionalidades já entregues.

## v0.1.0 — Experimental

- [x] Organizar as skills do Criador de Sites.
- [x] Incluir wireframe, extração e combinação de design systems.
- [x] Incluir scripts de captura, comparação, medição e validação.
- [x] Incluir template inicial de site.
- [x] Publicar documentação inicial.
- [ ] Validar a instalação em máquinas diferentes.
- [ ] Testar todos os fluxos ponta a ponta.
- [ ] Integrar e validar a base complementar de pesquisa referenciada por `expert-asimov`.

## v0.2.0 — Estabilização

- [ ] Testar a instalação limpa em Windows.
- [ ] Registrar versões de Python, bibliotecas e Claude Code usadas nos testes.
- [ ] Revisar mensagens de erro e instruções de recuperação.
- [ ] Completar a integração da base de conhecimento.
- [ ] Documentar resultados de testes reais.
- [ ] Melhorar exemplos e demonstrações públicas.

## v0.3.0 — Experiência de criação

- [ ] Ampliar os templates e exemplos de interfaces.
- [ ] Melhorar o fluxo de revisão responsiva.
- [ ] Adicionar mais verificações de acessibilidade e desempenho.
- [ ] Organizar uma galeria de projetos com autorização de publicação.
- [ ] Refinar a identidade visual oficial da NOVYRA nos materiais do repositório.

## Próximas versões — Visão de longo prazo

- [ ] Ampliar as capacidades criativas além da criação de sites.
- [ ] Explorar novos fluxos com agentes e automações.
- [ ] Evoluir a recuperação e consolidação de conhecimento.
- [ ] Investigar mecanismos de avaliação e aprendizado com histórico de uso.
- [ ] Avaliar novas integrações conforme necessidade e segurança.

## Como considero uma versão pronta

Antes de marcar uma versão como estável, quero:

1. Instalar o projeto do zero seguindo a documentação.
2. Executar cada skill principal com um exemplo real.
3. Conferir arquivos produzidos e dependências.
4. Validar os sites gerados em desktop e mobile.
5. Registrar limitações conhecidas e resultados dos testes.
6. Atualizar o changelog e criar uma release correspondente.
