# Exemplos

## portal-novyra

Landing page do próprio NOVYRA ("Create Beyond Limits"), criada com `/criar-site` a partir de uma arte (`reference.jpg`, 736x1308) enviada pelo autor do projeto, com a identidade NOVYRA Future Lab e a direção "portal para o desconhecido".

- Abra `portal-novyra/index.html` no navegador.
- `wireframe.txt`: a planta da etapa 1.
- `ESTADO.md`: as etapas, a paleta medida e as decisões.
- Capturas e comparações: geradas pelos scripts em `_capturas/` (fora do git). As principais estão em [`docs/images`](../docs/images) (`demo-*`).

A arte é usada só como exemplo deste repositório. Para reutilizá-la fora daqui, peça autorização ao autor.
